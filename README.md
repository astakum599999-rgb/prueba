# NexoISP para XAMPP

Descarga `nexoisp-xampp.zip` desde este repositorio y extrae su carpeta `nexoisp` dentro de `C:\xampp\htdocs`.

1. Inicia Apache y MySQL en el panel de XAMPP.
2. Abre `http://localhost/nexoisp/`.
3. Completa el instalador y crea tu administrador.
4. Ejecuta `INICIAR-WORKER.bat` para los procesos automáticos.

Incluye PHP y MariaDB/MySQL, panel compilado y código fuente. No requiere Node.js ni Docker para ejecutarlo. El ZIP no contiene configuración privada ni contraseñas. Consulta `LEEME.txt` y `PRUEBAS.txt` dentro del paquete.
